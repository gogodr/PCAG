# SceneManager icons

Generated with the built-in imagegen tool as one transparent pixel-art sprite sheet. The four quadrants are Add, Edit Script, Remove, and Expand. Expand rotates in the UI for Collapse. Add Event and Add Trigger share the Add icon; both remove controls share the Remove icon.

Final prompt:

> Use case: stylized-concept. Asset type: a single transparent 2-by-2 sprite sheet of four tiny interface icons for the PCAG adventure scene editor SceneManager form. Create four separate, consistent hand-pixelled icons, one precisely centered in each equal quadrant of a square canvas, with generous transparent space around each icon and no visible grid lines. Top left: plus sign for Add Event/Add Trigger. Top right: angle brackets with a short code slash for Edit Script. Bottom left: small trash can for Remove Event/Remove Trigger. Bottom right: simple right-facing chevron for Expand, which the app can rotate to indicate Collapse. Palette: warm brass/gold (#F0C36F) with restrained muted teal edge pixels (#79C3BC), on genuine transparency. Each glyph must be chunky, high contrast, and legible when its quadrant is displayed at 18 by 18 pixels. Consistent pixel stroke weight and scale. No words, letters, labels, numbers, tile backgrounds, buttons, gradients, glow, shadows, or extra symbols. Keep exact 2-by-2 alignment and spacing.

Original asset: [scene-manager-icons.png](../../apps/creator/src/assets/scene-manager-icons.png).

Redraw all four glyphs of Image 1 in the exact visual language of Image 2 while keeping their meanings and their top-left/top-right/bottom-left/bottom-right quadrant arrangement: plus, code brackets with slash, trash can, right chevron. Match the reference's crisp hand-placed pixel clusters, thick near-black/navy outer outline, warm gold metallic bevel and cream highlights, and dark teal shaded interior. Remove the flat mint outline and smooth flat fills of Image 1. Treat each icon as a tiny dimensional game-editor artifact, but simplify to be legible when shown inside a 20x20 pixel button. Keep all four icons at similar apparent size, precisely centered in equal quadrants with generous clear separation. Genuine transparent background throughout, no quadrant backgrounds, no button shapes, no text, no extra objects, no glow. Preserve the edit target's square sprite sheet layout.
