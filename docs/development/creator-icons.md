# Creator icon assets

The transparent PNG icons in `apps/creator/public/icons/` were generated for this project with the imagegen tool on 2026-10-23. They replace the creator's temporary inline SVG and Unicode symbols for folders, images, files, audio, scene backgrounds, hotspots, add scene, and rename scene. No third-party icon pack is used.

The original generated files are preserved in the Codex image generation output for this session. The checked-in PNGs are the source assets used by the creator build.
