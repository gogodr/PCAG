# Action cursor artwork

The nine cursors in [action-cursors.png](../../packages/runtime/assets/action-cursors.png) were generated with the built-in image generation tool. The transparent 3-by-3 sheet is cropped into native CSS cursors by the player at runtime.

Prompt used:

> Use case: stylized-concept. Asset type: 3 by 3 sprite sheet of nine game cursor pictograms, transparent PNG, for a point-and-click adventure player. Create exactly nine separate icons in an evenly spaced 3-column by 3-row grid, each centered in its own square cell, with generous empty transparent padding so cells can be cropped cleanly. Row 1: eye (View), walking boots or footprints (Move to), speech bubble (Talk to). Row 2: forward pushing hand (Push), hooked pulling hand (Pull), open door (Open). Row 3: closed door (Close), offered gift (Give), hand using a small tool (Use). Crisp chunky pixel-art / modern adventure game icon style, warm ivory and brass gold highlights with dark navy outlines, matching a dark navy and teal editor palette. Strong silhouette at 32px, consistent stroke and scale, no letters, no captions, no shadows outside each cell, no background, no watermark. Transparent background is essential.

The [empty crosshair](../../packages/runtime/assets/empty-crosshair.png) and [scene element icon sheet](../../apps/creator/src/assets/scene-element-icons.png) were also generated with the built-in image generation tool. Their prompts:

> Use case: stylized-concept. Asset type: one custom game cursor icon PNG. A single hollow crosshair centered in a square transparent canvas. Four short separated cardinal arms point toward a completely empty transparent center ring; make it read clearly as 'no available action'. Crisp chunky pixel-art in the same point-and-click adventure style as warm ivory and brass gold highlights with a dark navy outer outline, tiny muted teal accents. Strong silhouette at 32 pixels, symmetric, ample transparent padding around it. Exactly one crosshair; no words, no other symbols, no fill in the center, no backdrop, no shadow, no watermark. Genuinely transparent background.

> Use case: stylized-concept. Asset type: one transparent sprite sheet for a point-and-click adventure scene editor Elements panel. Exactly ten distinct small pictogram icons in a strict 4-column by 3-row grid with even cell spacing, centered in their own cells and transparent padding. Row 1 left to right: Box (outlined rectangle), Shape (editable polygon with three vertices), Image (framed landscape/picture), Overlay (two translucent image layers). Row 2: Player (standing adventurer silhouette), Walkable Area (footsteps on a dotted ground patch), Background (mountain landscape backdrop), SceneManager (small gear with lightning bolt). Row 3: SceneState (single room with two variable dots), GameState (globe with two variable dots), then leave the last two cells completely empty and transparent. Crisp chunky pixel art, warm ivory and brass gold highlights with muted teal and dark navy outlines, same visual family as a premium retro adventure editor. Each icon simple enough to read at 20 pixels, consistent scale, no letters, no text, no labels, no merged icons, no borders around the cells, no backdrop, no shadow, no watermark. Genuine transparent background.

The detailed sheet above is active. The Player icon keeps its hat-and-coat adventurer look. Every sheet cell renders at 30px inside the same centered 34px slot, with 2px of padding in the Elements tree and add menu.
