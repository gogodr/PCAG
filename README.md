# PCAG - Point-and-click adventure framework

PCAG is being rebuilt from the ground up. The full product scope and all 24 backlog items are retained. No rebuild implementation has started.

Work proceeds one backlog item at a time: implement, verify, present the result, and wait for user validation before advancing. The next item is **F01**, the focused reference review and architecture decisions.

The release objective remains a browser tool in which a nontechnical person can author, test, save, reopen, and export a complete small adventure without programming or developer intervention.

The previous source, dependencies, build outputs, setup instructions, decisions, and evidence are preserved in the [first-build archive](archive/README.md). There is currently no active application, package manifest, or build/test command. Tooling will be established in F02 after F01 is accepted.
